## 测量口径

- 使用 Release；同一数据、变换和输出规则。CPU 基线明确线程数，必做基线为单线程。
- 每组先 warm-up 10 次，再采样至少 50 次，报告中位数和 p95；CSV 保留每次原始数据。
- GPU kernel 用 CUDA events 计时；主机端端到端测量结束前同步 GPU，不能把异步提交耗时当作执行耗时。
- 分别报告变换、binning、H2D、raster kernel、D2H。端到端包含完成一帧所需的这些步骤，排除 OBJ 磁盘解析及图片编码 / 写盘；单独说明初始化 / 分配成本。
- 冷启动与静态场景缓冲复用必须标注，所有后端采用可比口径；profiling 与正式计时分开，避免采样开销污染数据。
- 至少覆盖 2 种分辨率 × 3 种三角形规模；naive CUDA 比较 3 种合法 block 配置。profiling 只选少量代表性场景控制工时。

推荐 CSV 字段：`commit,scene,width,height,triangles,backend,block_x,block_y,tile_size,iteration,transform_ms,binning_ms,h2d_ms,raster_ms,d2h_ms,total_ms`。不适用的阶段记为 0，并在报告解释。
